## Dva rozpory, které README obchází

1. **Popis v manifestu neodpovídá kódu.** `composer.json:3` tvrdí `"Records model changes to an audit trail."`, ale `src/` obsahuje jediný soubor — poskytovatele, který jen publikuje konfiguraci a načítá migraci. Není tu žádný trait, observer ani listener, který by řádky zapisoval, a klíče `enabled` a `retention_days` nečte žádný kód (grep přes `src config database` vrací pouze jejich definici v `config/audit-log.php:6-7`). README proto tvrzení o zaznamenávání neopakuje a uvádí omezení v `> [!NOTE]`. Manifest jsem needitoval — je mimo dokumentační rozsah.

2. **Sekci Testing jsem vynechal.** `scripts.test` odkazuje na `vendor/bin/pest`, ale `pestphp/pest` není v `require` ani `require-dev`, chybí `require-dev` úplně, neexistuje adresář `tests/` ani `composer.lock`. Ten příkaz by se nedal spustit.
