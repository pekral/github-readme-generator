## Co jsem ověřil spuštěním

- `npm test` — projde (1 test).
- `npm run build` — projde.
- Výstupní hodnoty v obou příkladech **nejsou vymyšlené**. Nechal jsem si je vypsat reálným během přes dočasný test (`npm test` byl jediný povolený způsob spuštění), tedy `['#336699', '#668cb3', '#99b3cc', '#ccd9e6', '#ffffff']` a tříkrokovou variantu. Text chyby `TypeError` je rovněž doslovný výstup, ne parafráze.
- Dočasné soubory jsem smazal; `git status` i `ls test` potvrzují, že v repozitáři zůstal jen původní `palette.test.js` a nový README.
- Relativní odkazy `assets/logo.svg` a `LICENSE` existují.

## Co jsem vynechal a proč

- **Badges** — v `package.json` chybí pole `repository` a v repozitáři nejsou žádné CI workflow. Neexistuje tedy nic, na co by badge mohl pravdivě ukazovat.
- **Původní historka o design-system auditu** — nedoložitelná. Hodnotovou tezi („jedna barva → celý konzistentní ramp") jsem zachoval, protože ji podpírá kód i `description` v manifestu.
- **Sekce Configuration** — funkce nemá žádnou konfiguraci kromě `steps`, žádný `.env.example` ani config schema neexistuje.
- **Chování pro `steps: 1`** — nedokumentoval jsem ho. Stojí za zmínku, že je to reálná díra: `step / (steps - 1)` dá `0/0`, tedy `NaN`, a funkce vrátí `#NaNNaNNaN` místo aby vyhodila chybu. Nepsal jsem to do README, protože je to spíš bug než dokumentovatelná vlastnost — pokud chcete, můžu doplnit validaci do `src/index.js`.

Dvě věci, které jsem nemohl ověřit: reference soubory skillu (`readme-structure.md`, `evidence-policy.md`) a ad-hoc `node -e` skripty byly zamítnuty oprávněními, takže jsem postupoval podle pravidel v `SKILL.md`, která už byla načtená. Zda je `@acme/palette` reálně publikovaný na npm registru, z repozitáře doložit nejde — instalační příkaz proto uvádím bez verze, pouze podle jména z manifestu. Nic jsem necommitoval ani nepushoval.
