- **Instalaci z npm registru.** Manifest nemá `repository` ani `publishConfig`, takže publikaci balíčku nemám čím doložit. Instalace je popsaná z lokálního checkoutu; z toho důvodu není v README ani `git clone` URL.
- **Library API.** `run()` je sice exportovaná, ale `package.json` nemá `main` ani `exports`, takže import podle jména balíčku není podporovaný a nedokumentuji ho.
