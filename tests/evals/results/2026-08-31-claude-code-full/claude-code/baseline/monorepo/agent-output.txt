**Co jsem záměrně vynechal**

- **Žádné badge a žádný odkaz na repozitář.** `git remote` ukazuje na `pekral/github-readme-generator` — to je nadřazený repozitář, ne tento workspace (leží uvnitř něj jako fixture v `tests/evals/`). Klonovací URL by tedy byla nepravdivá.
- **Žádná sekce Configuration** — v repozitáři není `.env.example`, config schéma ani env proměnná.
- **Žádné CI badge** — v repozitáři nejsou žádné workflow soubory.
- **Instalaci z registry jsem nezopakoval.** README jednotlivých balíčků uvádějí `npm install @acme/core` a `npm install -g @acme/cli`, ale publikaci na npm jsem nemohl ověřit, takže root README dokumentuje jen instalaci workspace (`npm install`) a na balíčkové README odkazuje.
